# 7. Business Problems Solved

## Q1. What is the total revenue generated by male vs female customers?

```sql
SELECT
    gender,
    SUM(purchase_amount_usd) AS total_revenue
FROM customer
GROUP BY gender;
```

### Objective

Analyze spending behavior based on gender.

---

## Q2. Which customers used discounts and still spent above average?

```sql
SELECT
    customer_id,
    purchase_amount_usd
FROM customer
WHERE discount_applied = 'Yes'
  AND purchase_amount_usd >= (
      SELECT AVG(purchase_amount_usd)
      FROM customer
  );
```

### Objective

Identify high-spending customers using discounts.

---

## Q3. Which products have the highest average review ratings?

```sql
SELECT
    item_purchased,
    ROUND(AVG(review_rating::NUMERIC), 2) AS average_product_rating
FROM customer
GROUP BY item_purchased
ORDER BY average_product_rating DESC
LIMIT 5;
```

### Objective

Identify top-rated products.

---

## Q4. Compare average purchase amount by shipping type

```sql
SELECT
    shipping_type,
    ROUND(AVG(purchase_amount_usd), 2) AS average_purchase_amount
FROM customer
GROUP BY shipping_type;
```

### Objective

Analyze spending trends based on shipping methods.

---

## Q5. Do subscribed customers spend more?

```sql
SELECT
    subscription_status,
    ROUND(AVG(purchase_amount_usd), 2) AS average_spend,
    ROUND(SUM(purchase_amount_usd), 2) AS total_revenue
FROM customer
GROUP BY subscription_status;
```

### Objective

Compare subscriber and non-subscriber spending patterns.

---

## Q6. Segment customers based on previous purchases

```sql
WITH customer_type AS (

    SELECT
        customer_id,
        previous_purchases,

        CASE
            WHEN previous_purchases = 1 THEN 'New'
            WHEN previous_purchases BETWEEN 2 AND 10 THEN 'Returning'
            ELSE 'Loyal'
        END AS customer_segment

    FROM customer
)

SELECT
    customer_segment,
    COUNT(*) AS number_of_customers
FROM customer_type
GROUP BY customer_segment;
```

### Objective

Perform customer segmentation analysis.

---

## Q7. Find top purchased products within each category

```sql
WITH item_counts AS (

    SELECT
        category,
        item_purchased,
        COUNT(customer_id) AS total_orders,

        ROW_NUMBER() OVER (
            PARTITION BY category
            ORDER BY COUNT(customer_id) DESC
        ) AS item_rank

    FROM customer
    GROUP BY category, item_purchased
)

SELECT *
FROM item_counts
WHERE item_rank <= 3;
```

### Objective

Identify best-selling products in each category.

---

## Q8. Are repeat buyers likely to subscribe?

```sql
SELECT
    subscription_status,
    COUNT(customer_id) AS repeat_buyers
FROM customer
WHERE previous_purchases > 5
GROUP BY subscription_status;
```

### Objective

Analyze relationship between customer loyalty and subscriptions.
