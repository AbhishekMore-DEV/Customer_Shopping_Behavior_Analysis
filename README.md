## Project Title
Customer Shopping Behavior Analysis Using SQL, Python & Power BI

---

# Project Description

Customer Shopping Behavior Analysis is a data analytics project using SQL, Python, and Power BI to analyze customer purchasing patterns, revenue trends, subscriptions, and product performance. The project includes data cleaning, business analysis, customer segmentation, and dashboard visualization.
